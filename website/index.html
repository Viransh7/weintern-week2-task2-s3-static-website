Static website hosting on AWS S3

This page is served straight from an S3 bucket. No servers to patch, no instances to run: just files, a bucket policy and a website endpoint.

See the setup Test the 404 page

About this project

Built as part of the WeIntern Cloud Computing internship. The goal was to deploy a static site to the cloud, configure public read access with a bucket policy, and set custom index and error documents.

Tech stack

Amazon S3

Stores the HTML, CSS, JS and image files and serves them through its static website endpoint.

Bucket policy

Grants public s3:GetObject on every object, and nothing else.

CloudFront

Optional CDN layer that caches the site at edge locations and adds HTTPS.

How a request is served

  1. Browser requests the site URL.
  2. CloudFront (optional) returns a cached copy, or fetches from S3.
  3. S3 website endpoint checks the bucket policy and returns the object.
  4. Missing paths return error.html with a 404 status.
